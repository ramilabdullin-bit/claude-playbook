# Подключение нового кабинета Ozon: три ловушки

## 1. Client-Id ≠ префикс рекламного логина

Рекламный логин выглядит как `103231747-1788767273180@advertising.performance.ozon.ru`,
и первое число ОЧЕНЬ похоже на Client-Id. Это не он. У рабочего кабинета
проверено: Client-Id `76973`, а рекламный префикс `100097740`.

Ozon на неверную пару отвечает `{"code":5,"message":"Invalid Api-Key"}` —
то есть жалуется на КЛЮЧ, хотя неверен идентификатор. Не гадай: Client-Id
берётся только из ЛК → Настройки → Seller API, там же, где Api-Key, и они
выдаются парой.

Проверка одной командой до всякой настройки:

```python
requests.post("https://api-seller.ozon.ru/v3/product/list",
              headers={"Client-Id": cid, "Api-Key": key},
              json={"filter": {}, "limit": 1, "last_id": ""})
```

## 2. Аналитика молча отдаёт МЕНЬШЕ метрик

`/v1/analytics/data` у кабинета без расширенной аналитики возвращает не все
запрошенные метрики — например две вместо шести — и НЕ говорит, какие
именно. Раскладка ответа по позициям (`zip(METRICS, row["metrics"])`) в этот
момент подписывает выручку как «показы в поиске», и это никак не заметно.

Правильно: сравнить длину ответа с длиной запроса; не совпало — переспросить
только гарантированный минимум (`ordered_units`, `revenue`) и честно
оставить недоступное нулями.

## 3. Рекламные ключи не должны ронять сбор продаж

Ключи Seller API и Performance API — разные, живут отдельно и перевыпускаются
отдельно. Если сбор кабинета делает и то и другое одним куском, перевыпуск
рекламной пары (401 на токене) уносит и продажи, хотя они собираются рабочим
ключом. Разводить в разные try, ошибку рекламы возвращать полем, а не
исключением.

## Порядок подключения

1. Проверить пару Seller API живым запросом — до записи в конфиг.
2. Проверить пару Performance API (`/api/client/token` → `/api/client/campaign`).
3. Завести кабинет ВЫКЛЮЧЕННЫМ, если чего-то не хватает: неполный кабинет в
   панели ломает чужие экраны.
4. Определить кабинет в смежных системах не по названию, а по данным: у
   портала e-comportal кабинет Ozon опознаётся по складам (`*_РФЦ` бывают
   только у Ozon), а принадлежность карточки — прямым запросом с фильтром.
5. Догрузить историю (30 дней) сразу — иначе графики и «средний день»
   заработают только через месяц. Лимит аналитики жёсткий: грузить неделями
   с паузами, 429 прилетает мгновенно.
