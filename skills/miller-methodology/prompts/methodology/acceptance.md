# Приёмка: «не отвечай "сделано"» - доказательства командами

**Когда применять:** в конце задачи, когда агент отчитался о готовности. Переводит приёмку из режима «сделал?» в режим «покажи». Запрещает слово «проверено» без вывода команды, требует явно назвать непроверенное, заканчивается вопросом про то, что исполняется вне периметра проверки.
**Источник:** гайд `pochemu-ii-agent-govorit-gotovo` 337-353; `training/guides-review.md` §4.4.

## Промпт

```prompt
Не отвечай «сделано» и «проверено». Мне нужны доказательства.

По каждому пункту работы дай ровно это:

Какую команду ты запустил, чтобы убедиться, что пункт работает. Приведи саму команду и её вывод целиком, без сокращений.

Если команду не запускал - так и напиши: «не запускал». Не заменяй это словами «проверил визуально» или «логика корректна».

Что из сделанного исполняется вне того периметра, который покрывает твоя проверка. Фоновые процессы, отдельные скрипты, задачи по расписанию, обработчики очередей - всё, что стартует не тем же способом, что основное приложение. Для каждого такого куска: запускал ли ты его отдельно и что он вывел.

Кто вызывает каждую новую функцию, которую ты добавил. Найди вызов поиском по проекту и покажи файл и строку. Если вызова нет - скажи прямо.

Затем отдельным блоком: три способа, которыми заявленный результат может НЕ достигаться, хотя все твои проверки зелёные. Ищи всерьёз.

В конце - одна строка: что из этой работы я обязан посмотреть глазами сам, потому что автоматической проверкой это не ловится.
```

Тест на формулировку критерия (там же, 252-258): «может ли агент удовлетворить этот критерий, ничего не сделав?». «Проверь, что всё работает» - может; «Запусти сборку и покажи вывод» - уже сложнее; «Запусти, нажми кнопку, покажи, что появилось на экране» - почти нечем. Правило гайда: если проверка ничего не находит, первым делом меняй формулировку.

## Адаптация под Контент-завод

- Почти весь завод «исполняется вне периметра»: cron, очередь публикаций, ночной цикл. Пункт про фоновые процессы - главный.
- «Опубликовано» = JSON ответа Bot API + ссылка на пост, «отчёт отправлен» = message_id в Telegram; «код написан» доказательством не считается.
- Для независимой приёмки с чистым контекстом - субагент `.claude/agents/qa-acceptor.md`; этот промпт - для самого исполнителя.
- Короткая версия из практикума: «Покажи результат работы, а не описание работы. Запусти и выведи то, что выдал, целиком. Если не запускается - покажи текст ошибки полностью» (`aug-day2` п.17).
