# Оркестратор: возьми план, запусти субагентов, отметки в файле плана

**Когда применять:** когда план финализирован (ноль NOTE), фазы распределены на субагентов и сказана guard-фраза. Второй промпт - когда оркестратор остановился и непонятно, где он.
**Источник:** практикум СмыслоКод, август 2026, День 1, шаг 7.3 (`training/source/prompts/aug-day1-karkas-instruction.md`); `training/dashboard-review.md` §3.2.

## Промпт 1. Запуск

```prompt
Ты оркестратор. Возьми последний план из папки plans/ - если их несколько, покажи список и спроси, какой брать.
Запусти столько субагентов, сколько тебе нужно. Твоя задача - выполнить этот план целиком.
В работу включи проверку безопасности и тесты.
По каждой завершённой фазе проставляй отметку прямо в файле плана.
Всегда отвечай на русском.
```

Если фаз в плане ещё нет:

```prompt
Разбей этот план на фазы и распредели их под многоагентную работу, чтобы каждый субагент мог взять свою фазу.
Всегда отвечай на русском.
```

## Промпт 2. Оркестратор остановился

```prompt
Ты остановился. Покажи: какая фаза сейчас в работе, что уже сделано, что мешает продолжить. Если ждёшь моего решения - задай вопрос прямо. Если упёрся в ошибку - покажи её и почини сам.
Всегда отвечай на русском.
```

## Адаптация под Контент-завод

- «Выполнить план целиком» у нас ограничено guard-фразой: оркестратор берёт фазу N, не весь план, - «Реализуй фазу N по плану». Целиком - только для ночных сборок в отдельном worktree с бюджетом и stop-условием (правило «любой цикл - с бюджетом, верификатором и stop-условием» из `CLAUDE.md`).
- Перед отметкой `[x]` фазы - `self-check-before-done.md`, после всех фаз - `done-check.md` и приёмщик `qa-acceptor`.
- Отправляющие узлы субагенты собирают выключенными; включение - только основатель.
- Промпт оркестратора для конкретного плана должен лежать в самом плане отдельным блоком (шаг 7.2 практикума).
