# Впекаемый текст — отдельным полем, не из свободного ТЗ

**Случай (content-factory, 24.09.2026).** Сборщик ролика вытаскивал подписи
из `notes` брифа: «любые короткие фразы в кавычках». Но `notes` — раскадровка
для людей: кавычки там — текст ЭТИКЕТКИ («АКВАРОСА 2%», «0,9%»), плюс
пометки «⚠ убраны медзаявления», markdown, «сверить с этикеткой». В кадр ушёл
бред. Чат-агент не видел ролик и заказал платные перезаказы вслепую.

## Правило

1. **Контракт:** всё, что попадает в кадр/на картинку, — явное поле
   (`captions: [str]`), дословно. Свободный текст рендер не читает никогда.
2. **Без поля — факты из данных** (название карточки: тип, %, объём), не догадки.
3. **Гард кодом в единой точке рендера** (не в каждом вызывающем): длина,
   служебные маркеры (⚠, `**`, `#`, нумерация, «сверить/согласовать»,
   оборванное `...`). Та же проверка на стороне заказчика — ранний отказ.
4. **Рядом с артефактом — sidecar** `<файл>.json` с тем, что впечено; агент
   читает его + лист кадров, а не гадает по ТЗ.
5. **Правка текста ≠ новая генерация.** Храни оплаченный исходник (клип/кадр)
   и делай режим «перерендер только текста» за $0.

## Проверка
Demo подаёт реальный мусорный бриф и утверждает: ни одна фраза из notes не в
подписях; плохие captions роняют сборку до ffmpeg.
