# Пустой текст из PDF — не «это скан», а сломанный разборщик

Код читает PDF одним разборщиком и решает по длине результата:

```python
text = "\n".join(p.extract_text() or "" for p in PdfReader(path).pages).strip()
if not text:
    read_paths.append(path)   # «скан» — пусть модель прочитает сама
```

`pypdf` спотыкается на некоторых генераторах PDF (`Invalid CID width
range`, битые таблицы шрифтов) и возвращает **пустую строку вместо
исключения**. Ветка «это скан» срабатывает на документе, у которого
текстовый слой есть и он полный.

Дальше всё выглядит исправным: ответ приходит, ошибок нет. Но

- модель читает PDF глазами — ход дорожает в разы;
- разбор реквизитов регулярками не запускается вовсе (ему нечего парсить),
  и агент остаётся без проверенных цифр;
- в журнале только `WARNING PDF не разобран`, которое никто не читает.

**Реальный случай (buh-agent, 08.09.2026):** из 57 присланных в бота PDF
`pypdf` не прочитал 20 — все УПД от маркетплейса. `pdftotext -layout`
читает эти же файлы целиком, по 31 000 символов каждый. За день бот
потратил 16,71 доллара на 16 обращений при среднем 0,3 в остальные дни.
На корпусе из 1054 документов, приходящих из своей 1С, `pypdf` не ошибся
ни разу — то есть по одной выборке проблему не увидеть.

## Правило

1. **Два разборщика, а не один.** `pypdf` быстрый и без внешних вызовов —
   оставить первым. Пусто или подозрительно мало (< 50 символов) — звать
   `pdftotext -layout` (poppler, уже стоит в системе). Берём тот
   результат, что длиннее.
2. **Порог, а не `if not text`.** Разборщик отдаёт и «пять символов из
   колонтитула» — формально не пусто, а по сути ничего.
3. **Логировать факт подмены** (`прочитан через pdftotext, N символов`) —
   это единственный след, по которому потом видно масштаб.
4. **Считать на всём корпусе, а не на одном файле.** Прогнать оба
   разборщика по всем документам и напечатать три числа: сколько прочёл
   первый, сколько спас второй, сколько не читается совсем. «Совсем» = 0
   значит настоящих сканов нет и OCR писать не надо — экономия целой
   задачи.
5. **Фолбэк ставить в общую функцию чтения**, а не в один вызов: тем же
   `pdf_to_text` пользуются и веб-чат, и сборщики реестров.
