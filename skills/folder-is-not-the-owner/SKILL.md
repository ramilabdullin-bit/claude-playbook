description: Use when building or debugging a registry/report that assigns documents (invoices, UPD, acts, contracts) to a client BY THE FOLDER they lie in — an office share, a Z:\ archive, a per-client directory. Also use for "клиент должен сумму, которой не выставляли", "в отчёте чужой счёт", "дебиторка не бьётся у одного клиента", or when the same file name shows up under several folders. The folder is a filing decision, not the document's party: read the party (ИНН) from inside the file and drop what doesn't belong.

# Папка — не владелец документа

**Случай (15.09.2026, дебиторка).** Мукминов «должен» 199 150 ₽. Счёт
№ 141 на эту сумму выписан Промтрасту, но бухгалтерия положила копию и в
папку Мукминова. Реестр относит счёт к клиенту по папке — и у Мукминова
появился долг, которого нет. Заодно у Промтраста висело 100 ₽: локальные
копии PDF складывались по имени файла, и сумма читалась из прежней
редакции из папки «старые» (199 150 вместо 199 050).

**Три правила для любого сборщика «папка → клиент»:**

1. **Сторона документа берётся из самого документа.** У счёта есть
   «Покупатель … ИНН»; у УПД — покупатель; у акта — контрагент. Сравнивать
   с тем, к кому отнесли по папке. Простой и устойчивый критерий: документ
   чужой, если его ИНН у ДРУГОГО клиента встречается чаще, чем у этого
   (`build_registry.drop_foreign`). Не «большинство» — у клиента с одним
   счётом большинства нет. Чужое — не учитывать и печатать предупреждение
   с номером и суммой, чтобы бухгалтерия переложила файл.
2. **Локальная копия файла именуется по полному пути, не по имени.** Одно
   имя «Счет № 141 от 30 августа» лежит в трёх папках (клиент, чужой
   клиент, «старые»); без префикса `md5(путь)[:8]__имя` копии затирают друг
   друга, и сумма приходит из чужого файла.
3. **Среди копий одного документа побеждает поздняя.** Сначала дата в
   имени (переизданный счёт), потом PDF важнее одноимённого xlsx (1С пишет
   xlsx на секунду позже, а сумму читают из PDF), потом время записи файла
   (папка «старые» записана раньше).

**Проверка, которая ловит это на живых данных:** для клиента с
подозрительным долгом открыть каждый его неоплаченный счёт и прочитать
«Покупатель». Один чужой ИНН — вот и весь долг.
