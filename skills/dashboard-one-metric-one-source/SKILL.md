# Одна метрика — один источник, и проверка сходимости

Панель почти всегда показывает одно и то же число в нескольких местах:
плитка, график, таблица-разбивка, текст сводки, ночной отчёт. Каждое из них
кто-то когда-то посчитал отдельно — и они расходятся. Владелец находит это
глазами и теряет доверие ко всем цифрам сразу, а не только к неверной.

## Как это выглядело (ozon-agent, 05.09.2026)

Одна и та же дата на одном экране: плитка «308 031 ₽», линия графика
«298 423 ₽». В сводной рядом с верным текстом — плитка «107 972 ₽, −87% ко
вчера» (сегодняшний неполный день из другого источника). Разбивка по
кабинетам показывала «0 ₽ за день» у кабинета, где сбор ещё не проходил.
Чинилось это четырьмя заходами по жалобам, вместо одного аудита.

## Правило

1. **Метрика считается ОДИН раз**, в одной функции, и раздаётся всем
   поверхностям. Не «каждый экран берёт откуда удобно».
2. **Источник для картинки и для подписи под ней — один и тот же.** Если
   график рисуется по API-B, то и плитка над ним считается по API-B, даже
   когда «свои» данные точнее: расхождение на экране дороже, чем 3%
   разницы в методике.
3. **Неполный сегодняшний день не участвует** ни в линии, ни в сравнениях.
   Сравнивать сутки со вчера вообще плохо (выходные, акции дают ±40%) —
   сравнивай со средним за окно.
4. **Прежде чем чинить одну жалобу — найди ВСЕ места**, где эта метрика
   считается: `grep` по имени поля, по формату вывода, по названию колонки.
   Починка одного экрана гарантирует новую жалобу через десять минут.

## Проверка, без которой это возвращается

Тест, который поднимает КАЖДУЮ страницу и сверяет поверхности между собой:

```python
# плитка = последняя точка её же графика
assert abs(num(orders_tile) - chart["Заказы"][-1]) <= 1
# сводная = сумма кабинетов
assert abs(combined_total - sum(per_cabinet)) <= len(cabinets)
# разбивка складывается в тот же итог, что и график
assert abs(sum(row_values) - chart_total) <= len(rows)
```

Он ловит именно тот класс расхождений, который иначе находит владелец.
Пример — `ozon-agent/test_coherence.py`.
